# DeepCausalMMM 2.0.0 Release Notes

## Summary

v2.0.0 adds a mandatory post-fit causal scenario layer to standard training.
The predictive GRU remains unchanged. After it finishes, the package learns a
conditional NOTEARS candidate media DAG and writes DMA-week structural
``do(channel=0)`` scenario artifacts.

## New outputs

Every standard ``ModelTrainer.train()`` run now writes:

- ``causal_attribution_report.json`` — aggregate direct, mediated, and total
  scenarios, fit metrics, assumptions, and diagnostics;
- ``causal_attribution_dma_week_channel.csv`` — observed and counterfactual
  predictions plus time-varying effects per DMA, week, and channel;
- ``causal_dag_positive.dot`` and, when Graphviz is installed,
  ``causal_dag_positive.svg`` — the positive, exact acyclic DAG used for
  intervention propagation.

## Method

The DAG is learned after residualizing log-transformed media against measured
pre-treatment controls, DMA fixed effects, and Fourier time features.
Conditional NOTEARS selects a sparse candidate graph. A monotone nonlinear
outcome equation then evaluates direct and total structural scenarios. The
new DAG is deliberately outside the GRU prediction loss, protecting the
existing predictive fit.

## Interpretation and compatibility

The standard predictive API is retained, but v2 requires a fitted
``UnifiedDataPipeline`` with raw non-negative media, KPI, and measured
pre-treatment controls so the mandatory causal stage can run. Existing users
should read the [Sphinx migration guide](../docs/source/migration_v2.rst).

These estimates are assumption-based structural simulations. The learned DAG
is observational, and support, placebo, and stability diagnostics do not
prove no unmeasured confounding. Individual channel ``do(0)`` effects overlap;
they are not additive budget shares without an allocation method such as
causal Shapley.
